# 📝 Changelog - Обновления TreasuryBot

## 🎉 Версия 2.0 - Глобальный рефакторинг (13 августа 2026)

### ✨ Новые возможности

#### 1. **Новая структура меню**
- **💰 Мой бюджет** - личный раздел для ВСЕХ пользователей (включая админов и казначеев)
  - Лицевой счёт
  - История платежей
  - Штрафы
  - Реквизиты
  - Оплата
  
- **💼 Бюджет клуба** - раздел для казначея и админа
  - Начисление взносов
  - Подтверждение платежей
  - Список участников
  - Штрафы
  - Расходы
  - Статистика

- **👑 Управление** - только для админа
  - Пользователи
  - Настройки
  - Журнал действий
  - Экспорт данных

#### 2. **Улучшенная навигация**
- ✅ Кнопка "🔙 Назад" теперь возвращает на **предыдущий экран**, а не в главное меню
- ✅ История навигации (до 10 экранов)
- ✅ Middleware для отслеживания перемещений
- ✅ Все сообщения редактируются вместо отправки новых

#### 3. **Отмена действий**
- ❌ Кнопка "Отменить" во всех многошаговых процессах:
  - Оплата взноса
  - Начисление штрафа
  - Добавление пользователя
  - Изменение настроек
- ❌ Команда `/cancel` в текстовых полях

#### 4. **Улучшенные уведомления**
- 📬 При **начислении взноса** - все участники получают уведомление
- ✅ При **подтверждении платежа** - пользователь получает красивое уведомление
- ❌ При **отклонении платежа** - пользователь получает уведомление с причиной
- ⚠️ При **начислении штрафа** - пользователь получает уведомление

#### 5. **Поддержка webhook для хостинга**
- 🌐 Новый файл `webhook.py` для запуска через webhook
- 🚀 Инструкции по деплою на **Railway** (рекомендуется)
- 📄 Инструкции по деплою на **PythonAnywhere**
- ⚙️ Новые настройки в `.env`:
  - `USE_WEBHOOK` - включить webhook режим
  - `WEBHOOK_DOMAIN` - домен для webhook
  - `WEBAPP_HOST` / `WEBAPP_PORT` - хост и порт

### 🔄 Миграция со старой версии

Если у вас уже запущен бот версии 1.x:

1. **Сделайте бэкап базы данных**
   ```bash
   cp treasurybot.db treasurybot.db.backup
   ```

2. **Обновите код**
   ```bash
   git pull
   pip install -r requirements.txt
   ```

3. **Обновите .env** (добавьте новые переменные):
   ```env
   # Webhook settings (опционально)
   USE_WEBHOOK=false
   WEBHOOK_DOMAIN=
   WEBAPP_HOST=0.0.0.0
   WEBAPP_PORT=8000
   ```

4. **Перезапустите бота**
   ```bash
   python main.py
   ```

Все данные (пользователи, платежи, штрафы) сохранятся!
